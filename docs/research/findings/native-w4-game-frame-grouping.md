# W4 game-frame grouping

The W4 recorder files calls under an emulator `RunFrame` sequence. That sequence can end during a game frame. The independent Opus NB-W4-TICK78 report traced record 16's tick-78 rectangle writer into emulator sequence 79, although collision and FXO's integrator entry both belong to gfc 78991. Its source `calls.tsv` SHA-256 is `8187d67a02c232e50923b5cff3ed0f5e4a692a5501d8e869ee46828ffed5cf04`; source `frames.tsv` is `f1f174e1b0824c5c871cd73b01f4dde14ceccb445f1bedbd78d6b11ccb692540`. Frame-end list and RAM watches may be sampled before the integrator. Rows 64–68, 70, 72, 73, 75, 76, 78 and 80 are mid-game-frame in that capture. Clamp-route rows and downstream comparators must not treat those watches as the end of game tick `t`.

The Opus NB-GFC-PC study found seven ov6 Thumb stores of the battle clock. Each stores an incremented `r1` into `r0 == 0x020A0F10`, with opcode `0x6001`. The primary PC is `0x0214DBD6`. The other stores are `0x0214DDCA`, `0x0214DE6E`, `0x0214DEB6`, `0x0214DF74`, `0x0214DF92` and `0x0214DFBA`. ARM9 `0x0208C020` stores a reset through `r5` with opcode `0x6005`. The raw overlay9_6 halfwords and ARM9 reset halfword were checked again for this change. The integrator entry remains ARM9 `0x02082E10`, opcode `0xE92D4FF8`.

The gfc store is scheduler task `0x9A000`, after fighter and ObjShot work and before collision `0x9E000` and integrator `0xA1000`. A marker with `r1 = G` opens collision frame G. The integrator G closes the comparison point. The W4 carrier sample keeps identity, wrapper and Q12 position from `geo_visit` but takes its fine rectangle from the replayed state **at integrator entry**, after that collision block's rectangle writers. `native_carriers.read` compares this sample strictly with the FXO integrator sample keyed by the same gfc. No tolerance, record exclusion or tick shift is applied. A writer in the fighter task after integrator G affects the next integrator sample. `native_bodies.decode()` keeps grouping by emulator sequence for both plans: its starting rectangles come from the frame-end list walk, and fighter-task writes before the next collision must remain on that list-walk clock. The marked synthetic W4 input now gives all 172 body rows byte-identical to the legacy input.

The new `native-body-game-frame/v2` capture plan registers all seven bump sites, reset and integrator. The decoder checks opcode, clock address, gfc step, duplicate markers, one collision pass and one integrator per gfc, and that the collision-end emulator row's gfc agrees with the marker. Missing registration, writer hooks or marker calls refuse. A first live capture must show 172 Thumb markers matching the 172 frame-end gfc rows before this path is credited. No retained capture has a Thumb hook hit; the C++ native hook test covers both halfword alignments but does not call `ARMv5::CheckCallHook`. That method lives in melonDS `src/ARM.cpp` and needs a constructed `ARMv5` and `NDS` interpreter with pipeline state. The standalone `test_native_hooks.cpp` links only `NativeHooks.h`; driving the real method requires a native emulator test build, outside this no-emulator, no-pinned-recorder-change job. The first live capture remains the witness.

A window can begin after the previous game's gfc marker. Before the first bump marker, `game_frames()` accepts only registered W4 body hook PCs from `ALL_HOOKS` and the integrator PC, each with its pinned opcode. Those calls can be the tail of the previous collision/integrator pass or the fighter/ObjShot/ov11 work before the next marker in the ov6 task order. It records their count and ordered PCs in `entry[0].pre_marker_calls`. One marker per emulator sequence, one marker per row, and sequences limited to the row range force the first marker and its prefix into sequence 0. Row 0's end-of-sequence list walk already includes the prefix's effects. Body decoding skips the prefix while retaining emulator-sequence grouping; carrier replay skips it because the seeded walk includes its effects and there is no FXO sample for gfc `g0-1`. A reset before the first marker, a W3-only or unknown PC, a wrong opcode, or a call after a later reset and before another marker refuses. `game_frames()` enforces complete marker coverage before either `decode()` or `carriers()` can use the groups; the first live capture must account for its prefix and still contain one complete marker/collision/integrator block for each of the 172 frame-end gfc rows.

The committed `train-kind25-w4.json.gz` fixture contains the retained W4 call stream. `test_native_game_frames.py` inserts synthetic markers before each `geo_begin` and integrator samples at a structural call-order cut. It scans after `geo_end` for the first element cluster containing a fighter-setter caller LR, or the ov11 preamble; no tick list or FXO value chooses the cut. This places the tick-78 writer before its integrator and the animation-start writers at ticks 9, 62, 99 and 120 after the preceding integrator. Compact FXO1/FXO2 fixtures retain all 172 frames, 2666 record rows, 2666 element rows and 172 FXT heartbeat lines from each raw log. The source FXO1/FXO2 log SHA-256 values are `df1f5a6b4d26d0d9932b90a89e4f94187760af7976ae86524d9238b2368abebc` and `e688466fbc85fc7a7c895a2c3bff70699e320490ff46c92691c535b9db162c54`. The strict comparator reports 2666 agreements and zero refusals in each run. Removing marker grouping reproduces five disagreements, including gfc 78991. A live marker and integrator capture must still establish the cuts directly in W4.

`native-w4-game-frame-oracle.py` imports no production decoder. It reads the committed W4 and FXO call/clock rows, then checks the five record-16 transitions at ticks 13, 78, 82, 98 and 102. Each writer follows that frame's visit and precedes the next collision begin. The tick-78 writer carries emulator sequence 79 while its game-frame writer block and both FXO samples carry gfc 78991. Its `--mutate-emulator` mode refuses at tick 78. The oracle covers those five transitions; the structural rule supplies the synthetic cuts for the full 2666-sample comparison without FXO input.
